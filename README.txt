# Template Undangan Premium

Template ini sudah berisi:
- Cover foto full-screen
- Nama mempelai
- Profil mempelai
- Countdown
- Akad & resepsi
- Galeri 4 foto
- Google Maps
- RSVP WhatsApp
- Wedding Gift + tombol salin rekening
- Alamat kirim hadiah + tombol salin
- Animasi scroll
- Tombol musik

## Cara mengganti data pelanggan
Buka `index.html` di GitHub lalu ubah teks yang bertanda:
- Nama Pria / Nama Wanita
- tanggal dan jam
- alamat
- nomor rekening dan nama pemilik
- nomor WhatsApp
- link Google Maps

Foto pelanggan diletakkan di folder `images/`, lalu nama file di HTML diganti sesuai foto.

Catatan: nomor rekening, alamat, dan nomor WhatsApp di template adalah DATA CONTOH. Ganti sebelum dipakai pelanggan.
